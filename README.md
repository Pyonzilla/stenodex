# StenoDex V8.07
https://pyonzilla.github.io/stenodex/

Offline Plover dictionary lookup and steno practice.

## Features
* Search your dictionary translations or strokes; customize diagrams, layouts, profiles, and themes.
* Practice lessons, quotes, words, numbers, symbols, phrases, briefs, and problem words based on your dictionary.
* Set daily goals; track speed, accuracy, strokes, and progress.
* Import/export settings and practice data. Data stays on your device.

## Mobile Installation (Offline Use)
This tool is built as a Progressive Web App (PWA). You can install it directly to your phone to use it like a native app, completely offline.

**Android (Chrome):**
1. Open the site in Chrome.
2. Tap the **three-dot menu** in the top right.
3. Select **Add to Home screen** (or **Install app**).

**iOS (Safari):**
1. Open the site in Safari.
2. Tap the **Share icon** at the bottom center.
3. Scroll down and tap **Add to Home Screen**.

Since this tool was built with AI assistance, I can't guarantee it will always work.
